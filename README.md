# 图像数字化 · 高中信息技术公开课课件

> 40 分钟 · 22 页 · 三张课堂动手任务卡 · 可直接编辑的 PPTX + 逐页讲稿

以「一张照片怎样变成电脑里的文件」为线索：先讲清**采样—量化—编码**三个环节各自的原理，再用**三张课堂动手任务**让学生亲自验证像素、分辨率与格式的差异，最后归纳到**存储空间估算**与**格式选择**。

---

## 一、这套课件解决什么

| 教学痛点 | 本课件的做法 |
| --- | --- |
| 学生听过「像素」，但指不出一个像素在哪、值多少 | 任务卡① 在系统自带工具里放大到 800%，用取色器读出坐标与颜色值 |
| 分不清分辨率与像素密度 | P11 把两个概念并置辨析，并给出 PPI 与 DPI 的区别 |
| 分不清位图与矢量图 | P19 左右对照，给出按场景选择的判断标准 |
| 只知道「文件很大」，不会算 | P14 给出公式与四档实测对照，P15 当堂迁移到两道新题 |
| 只会「另存为」，说不出为什么选这个格式 | P16 五标准横向对比，任务卡③ 要求给出有依据的选择结论 |

## 二、学情与目标

**学情**：约 40—50 名高一或高二学生，已具备基本计算机操作能力，对「照片能存进电脑」有直观感受，但尚未系统理解图像在计算机中如何表示。

**课后学生能做到**：

- 用自己的话说明采样、量化、编码各自做了什么；
- 解释分辨率影响细节多少、位深影响颜色多少；
- 估算一张图未压缩时占多少存储空间，并据此判断该用什么格式；
- 在课堂任务中独立用系统工具找到像素位置、读出图像尺寸与位深属性、比较四种格式的体积与画质差异。

## 五、怎么用

### 上课

1. 打开 `课件/图像数字化公开课.pptx`。
2. 讲稿已经写入每一页的**备注栏**，放映时按 Alt+F5 或用「演讲者视图」即可看到。
3. 三张任务卡在 `任务单/` 里，用 Word 或在线文档转成 A5 双面打印，一人一张。
4. 任务卡①③ 用到的图片已随课件附上，也可以让学生用自己拍的照片。

### 二次备课

- `设计规范/design_spec.md` 记录了每一页的目标、内容、事实编号与版式分工；
- `设计规范/spec_lock.md` 记录了配色、字号、页面节奏等不可随意改动的约束；
- `参考/事实研究.md` 与 `参考/事实溯源.json` 给出全部 47 条事实的出处，改动页面文案前请先核对。

### 两个 PPTX 版本怎么选

| | 主用版本 | 原生图表版 |
| --- | --- | --- |
| 全部元素 | 可编辑形状，与设计稿逐像素一致 | 可编辑形状 |
| P14 体积柱状图 | 形状绘制 | **PowerPoint 原生图表**，双击即可改数据 |
| P16 格式对比表 | 形状绘制 | **PowerPoint 原生表格**，可直接增删行列 |
| 适用 | 直接放映、打印、继续改版 | 需要改数据或改表格结构时 |

## 六、事实与素材的可靠性

- 课件中的每个数字与术语都可回溯：`参考/事实溯源.json` 为每条事实标注了来源、原文摘录与置信度，正文以 `[Fxxx]` 引用。
- 素材全部为公有领域、CC0 或 AI 生成，可在公开课录像与评课中放心使用；署名规则写在 `素材/图片授权.md`。
