## 目标

同一张图片分别存为 BMP、GIF、JPEG、PNG，比较体积并放大对比，给出选择理由。

## 需要用到的工具

| 工具 | 用到哪几个功能 |
| --- | --- |
| 画图 · 另存为 | 可选 BMP / PNG / JPEG / GIF |
| 资源管理器 | 按大小排序，一眼看出体积差别 |

> 别删原图，四个文件都留着。

## 操作步骤

1. 在「画图」中打开指定图片。
2. 分别另存为 PNG、JPEG、BMP、GIF 四种格式。
3. 在资源管理器中记录四个文件的体积并按大小排序。
4. 把 JPEG 与 PNG 都放大到 800%，找出画质差别最明显的位置。
