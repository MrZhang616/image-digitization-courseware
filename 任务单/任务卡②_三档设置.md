# 任务卡② 同一张图，三档设置

> 姓名：__________　同组：__________　用时：5 分钟　两人一组

## 目标

同一张图片做三档设置，并记录分辨率、颜色与体积三处差别。

## 需要用到的工具

| 工具 | 用到哪几个功能 |
| --- | --- |
| 画图 · 调整大小 | 可按像素或按百分比指定新尺寸 |
| 画图 · 另存为 | 可选 PNG / JPEG / BMP / GIF 四种格式 |

> 两张任务卡都只用系统自带工具。

## 操作步骤

1. 用「画图」打开同一张图片。
2. 用「调整大小」按像素改成 320 × 240，放大观察轮廓。
3. 另存为 24 位真彩 PNG 与 8 位索引色 GIF，比较体积。
4. 把两个文件都放大到 800%，比较边缘。

## 检查点（做完请打勾）

- [ ] 能说出分辨率变小后哪一处细节先消失
- [ ] 能说出索引色下哪些颜色不再精确
- [ ] 能比较两个文件的体积差别
