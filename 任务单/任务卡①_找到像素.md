# 任务卡① 找到像素

> 姓名：__________　同组：__________　用时：5 分钟　两人一组

## 目标

在放大状态下指出一张图片的像素边界，并用一个具体数值说出那个像素的颜色。

## 需要用到的工具

| 工具 | 用到哪几个功能 |
| --- | --- |
| 画图 | 铅笔、填充、取色器、文字、放大镜 |
| 照片查看器 | 放大镜、实际大小、按窗口大小显示 |

> 系统自带，不用装任何软件。

## 操作步骤

1. 打开「画图」，载入指定图片。
2. 用「放大」工具放到 800%，观察轮廓边缘。
3. 用「取色器」点住一个像素，记下读出的颜色值。
4. 用「调整大小」按像素改成 64 × 64，再放大看变化。

## 检查点（做完请打勾）

- [ ] 能说出像素的坐标
- [ ] 能说出一个颜色值
- [ ] 能指出放大后出现的方块边界
